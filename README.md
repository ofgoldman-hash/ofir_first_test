# התקציב המשפחתי – Family Budget

אתר לניתוח ההוצאות וההכנסות של המשפחה על בסיס תדפיסי בנק וכרטיסי אשראי.

## מה האתר עושה

- **ייבוא תדפיסים** – קבצי Excel (xlsx), CSV ו-"xls" שהבנקים מייצאים (כולל HTML/XML ו-Windows-1255).
  זיהוי אוטומטי של עמודות (תאריך / תיאור / סכום / חובה / זכות), מסך תצוגה מקדימה ומיפוי ידני,
  ודילוג על תנועות כפולות כשמייבאים את אותה תקופה שוב.
- **שכבות** – כל תנועה מסווגת לאחד מהסוגים:
  - **קבוע** – משכורת, משכנתא, ארנונה, ביטוחים, תקשורת, חוגים…
  - **משתנה** – סופר, דלק, מסעדות…
  - **חד-פעמי** – טיסות, מלונות, רכישות גדולות. אפשר לתת שם אירוע ("חופשה ביוון 2026") ולקבץ.
  - **לא נספר** – חיוב החודשי של כרטיס האשראי בעו"ש והעברות בין חשבונות (כדי שלא ייספרו פעמיים).
- **מאזן** – ממוצע חודשי של:
  - **מאזן קבוע (מבני)** = הכנסות קבועות − הוצאות קבועות
  - **מאזן שוטף** = אחרי הוצאות משתנות, לפני חד-פעמיות
  - **מאזן כולל** לתקופה, גרף עודף/גירעון חודשי, שכבות ההוצאה מול ההכנסה, פירוט לפי קטגוריה ואירועים.
- **כללי סיווג** – כללי ברירת מחדל לגופים ישראליים נפוצים + כללים שלכם ("כלל" על תנועה מחיל על כל הדומות).
- **זיהוי תשלומים קבועים** – תנועות שחוזרות כל חודש בסכום דומה מוצעות לסימון כקבועות.

## אבטחה – "האזור המאובטח"

- **הנתונים לא עוזבים את המחשב.** אין שרת. הקבצים מעובדים בדפדפן, והתנועות נשמרות ב-IndexedDB של הדפדפן.
- **הצפנה** – AES-256-GCM עם מפתח שנגזר מהסיסמה (PBKDF2-SHA256, ‏600,000 סבבים). נשמר רק מידע מוצפן.
- **חסימת רשת** – Content-Security-Policy קשיח (`connect-src 'none'`), כך שגם בטעות הדף לא יכול לשלוח מידע החוצה.
- **אין ספריות צד שלישי** – קריאת Excel/CSV ממומשת בקוד של הפרויקט.
- **נעילה אוטומטית** אחרי חוסר פעילות (ברירת מחדל 15 דקות).
- **גיבוי מוצפן** – הורדת קובץ גיבוי (מוצפן באותה סיסמה) מתוך "הגדרות"; משמש גם להעברה למחשב אחר.

> ⚠ אין שחזור סיסמה. בלי הסיסמה אי אפשר לפענח את הנתונים.
> ⚠ אל תשמרו תדפיסים בתוך הריפו – `.gitignore` חוסם קבצי csv/xlsx/xls/pdf ליתר ביטחון.

## הפעלה

האתר סטטי לגמרי. מספיק להריץ שרת מקומי:

```bash
npm start            # python3 -m http.server 8080 --bind 127.0.0.1
# ופתחו http://localhost:8080
```

אפשר גם לפרסם ב-GitHub Pages – הקוד ציבורי, אבל הנתונים נשארים מוצפנים בדפדפן של כל משתמש.
(Web Crypto דורש https או localhost; פתיחה ישירה של index.html מהדיסק לא תעבוד.)

## איך להוריד תדפיסים

- **עו"ש** – באתר הבנק: "תנועות בחשבון" → בחירת טווח תאריכים → ייצוא ל-Excel.
- **כרטיסי אשראי** (ישראכרט / מקס / כאל וכו') – "פירוט חיובים" → ייצוא ל-Excel.
  בכרטיסים החיובים מופיעים כמספר חיובי – האתר מזהה זאת ומהפך את הסימן (אפשר לשנות בתצוגה המקדימה).
- קבצי PDF אינם נתמכים. xls בינארי ישן – יש לשמור מחדש כ-xlsx או CSV.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `index.html` | דף יחיד, CSP |
| `js/crypto.js` | הצפנה/פענוח (Web Crypto) |
| `js/storage.js` | הכספת המוצפנת ב-IndexedDB, גיבוי/שחזור |
| `js/parser.js` | קריאת CSV / XLSX / HTML-xls, זיהוי עמודות, תאריכים וסכומים |
| `js/classify.js` | כללי סיווג, זיהוי תשלומים קבועים, חישוב השכבות והמאזן |
| `js/charts.js` | גרפי SVG |
| `js/app.js` | ממשק המשתמש |
